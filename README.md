# 🛒 Supermarket Billing & POS System

A Python-based Supermarket Billing and Point of Sale (POS) System designed to make billing easier, faster, and more efficient.

## ✨ Features
- Product registration with barcode.
- Barcode scanning and cart management.
- Discount coupon validation.
- Product price and tax updates.
- Clear cart and reset billing session.
- Receipt generation.

## 🛠️ Technologies Used
- Python
- SQLite Database
- VS Code
- Git & GitHub
